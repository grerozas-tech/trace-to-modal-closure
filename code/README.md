# Code and provenance

- `original/` — independently recovered archived source.
- `transcript_recovered/` — code copied verbatim from visible executable blocks in the frozen research transcript. Historical `/mnt/data` paths are intentionally preserved.
- `reference_reconstruction/` — validated executable reconstructions of three transient dependencies that were not independently archived.
- `portable/` — self-contained convenience execution directory combining required dependencies with path-only adaptations of the transcript-recovered late-stage runners.

Do not conflate these provenance classes. See `../PROVENANCE.md` and `../RECONSTRUCTION_VALIDATION.md`.

For experiment-by-experiment runnable coverage and the executable smoke test, see `../EXECUTION_COVERAGE.md` and `../SMOKE_TEST.md`.

`posthoc_audits/` contains explicitly post-confirmatory robustness scripts added during adversarial pre-release review.
