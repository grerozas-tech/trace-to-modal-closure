# Numerical result archive

- `main/`: result, diagnostic, summary, seed-summary, and primary-test tables supporting the main causal arc.
- `supplementary/`: falsification, negative-result, mechanistic-support, and robustness tables assigned to Supplementary Information.

Archived result tables remain the source of record for the reported Paper IV numerical values. Reference reconstructions are validated against these archived outputs rather than silently replacing them.
