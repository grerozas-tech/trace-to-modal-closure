# Provenance metadata

`Paper_IV_Master_Matrix_v03.xlsx` and `Paper_IV_Methods_Audit_v01.md` are working provenance/audit artifacts retained with the release.

The `historical/` subdirectory contains earlier source-recovery status reports preserved byte-for-byte as historical snapshots. Their statements that the package was not yet fully executable were accurate when written but are **superseded** by the current root-level `RECOVERY_STATUS.md` and `RECONSTRUCTION_VALIDATION.md`, after three validated reference reconstructions were added.
