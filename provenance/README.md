# Provenance archive

This directory contains historical source-recovery reports, the Methods/source audit, the master evidence matrix, and earlier package manifests.

These files document the recovery process chronologically. Some historical audit/report files therefore describe executable gaps that were still open at that stage. The current release status is defined by the root-level `RECOVERY_STATUS.md`, `PROVENANCE.md`, and `RECONSTRUCTION_VALIDATION.md`, which supersede those earlier status statements.

Raw research-conversation export JSON files are intentionally **not included** in the public repository because they contain unrelated material. Their filenames and SHA-256 hashes are retained in `SOURCE_EXPORT_HASHES.txt`; scientific artifacts recovered from those records are released separately under explicit provenance labels.
