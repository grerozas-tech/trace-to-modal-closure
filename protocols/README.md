# Frozen research protocols

`confirmatory/original/` contains independently recovered prospective confirmatory design JSONs.

`confirmatory/transcript_recovered/` contains exact design text recovered from visible transcript records where an independent archived copy was unavailable.

`diagnostic/original/` contains the recovered causal-relation diagnostic used to constrain the reconstructed relation convention.

The repository uses the manuscript wording **prospectively frozen confirmatory criteria/design**, not externally preregistered criteria.
