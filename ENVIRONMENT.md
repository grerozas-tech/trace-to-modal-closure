# Tested build environment

The v1.0.0 archival package was tested with:

- Python 3.13.5
- NumPy 2.3.5
- pandas 2.2.3
- Matplotlib 3.10.8
- latexmk 4.86 (John Collins, 11 Dec 2024)
- REVTeX 4.2 and standard TeX Live packages available in the build environment

`requirements.txt` pins the Python libraries needed for figure regeneration. The LaTeX toolchain is documented here rather than installed through pip.
